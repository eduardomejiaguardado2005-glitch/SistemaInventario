# SistemaInventario - Semana 5

Proyecto de Programación III aplicado a herencia en Java.

## Contenido
- Superclase Persona y subclases Cliente, Empleado, Estudiante, Docente y Visitante.
- Uso de extends, super(...) y protected.
- Ejemplo de shadowing para comprender por qué debe evitarse.
- Upcasting mediante un arreglo de Persona.
- Ejercicio de auditoría del proyecto.
- Jerarquía MovimientoInventario -> Entrada/Salida aplicada al inventario.
